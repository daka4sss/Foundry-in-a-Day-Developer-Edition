# Foundry in a Day — Developer Edition

**English** | [日本語](README.md)

> **Experience cutting-edge agent development in half a day!** Limited to the first 30 participants

Join us for a half-day workshop on **Microsoft Foundry**, Microsoft's platform for developing and operating AI agents. If you want to streamline your agent development, we encourage you to participate.

Microsoft will also provide the **Azure environment used during the workshop**.

---

## 📅 Event Details

| Item | Details |
|---|---|
| **Date and Time** | Monday, May 18, 2026, 2:00 PM–6:00 PM (doors open at 1:30 PM) |
| **Venue** | Seminar Room B, 31st Floor, Microsoft Japan Shinagawa Headquarters |
| **Instructor** | Microsoft Global Black Belt |
| **Capacity** | 30 participants (first come, first served) |

---

## 🎯 Goals

By the end of this workshop, participants will be able to:

- [ ] Explain Microsoft Foundry concepts and the latest developments
- [ ] Create a new agent using the SDK and CLI
- [ ] Implement an agent with Microsoft Agent Framework
- [ ] Deploy an agent to Foundry as a Hosted Agent
- [ ] Evaluate the agent they created

---

## 👥 Who Should Attend

- People who **develop agents as part of their day-to-day work**
- People who **plan to begin developing agents**
- People who can prepare an environment that meets the requirements in "[Before You Attend](#-before-you-attend)"

> ⚠️ **This workshop focuses intensively on code-based agent development. Please be aware of this before registering.**
> If you prefer GUI-based agent development, separate content focused primarily on GUI-based development and management can be delivered upon request. Please contact your Microsoft account representative.

## ✅ Before You Attend

Please prepare an environment that meets the following requirements **before the workshop**. See **[setup_EN.md](setup_EN.md)** for detailed setup instructions.

- [ ] Bring a **computer that can connect to the web and access the Azure portal**
  - Depending on your corporate computer's configuration, such as proxy settings, you may be unable to connect to our network.
- [ ] Install **Visual Studio Code**
- [ ] Have a **Python environment** available (Python 3.10–3.13 is supported)
- [ ] Be able to install the **REST Client extension** in **Visual Studio Code**
- [ ] Be able to install **Microsoft Authenticator** on your smartphone
- [ ] Be able to **clone repositories using the Git CLI**
  - If you are new to Git, complete [this training](https://learn.microsoft.com/training/paths/intro-to-vc-git/) beforehand
- [ ] A **GitHub account** is recommended
